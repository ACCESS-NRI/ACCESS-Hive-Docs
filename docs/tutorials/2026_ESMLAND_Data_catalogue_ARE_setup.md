# ACCESS Community Workshop on Land and Coupled Modeling

## Session: ACCESS data catalogues for model evaluation

This is the setup information for an ARE session for the session **"ACCESS data catalogues for model evaluation"**.

You can either open the ARE website directly from the [Interactive Data Catalogue](https://access-nri.github.io/interactive-data-catalogue/) or via this link ([ARE](https://are.nci.org.au/)).

### Steps

1. After you log in, click **JupyterLab**
2. **Walltime**: 2 hours 
3. **Queue**: `normalbw`
4. **Project**: `nf33`
5. **Storage**: `gdata/nf33+gdata/xp65+gdata/oi10+gdata/fs38`
   - Optional projects (listed below) can be added in the same way, e.g. `gdata/nf33+gdata/xp65+gdata/oi10+gdata/fs38+gdata/<optional_project>`
6. **Module directories**: `/g/data/xp65/public/modules/` (to load the Python conda environment)
7. **Modules**: `conda/analysis3`
8. Click **Launch**

Then you will have a JupyterLab session loaded with the correct setup to load in your dataset!
