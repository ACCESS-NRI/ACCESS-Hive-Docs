# ACCESS-NRI Intake Catalogue

The ACCESS-NRI Intake catalogue aims to provide a way for Python users to discover and load data across a broad range of climate data products available on _Gadi_. For an introduction, see [ACCESS-NRI Intake catalogue](/model_evaluation/data/finding/access_nri_intake).
