# Sharing ACCESS Data
ACCESS-NRI has a number of options to support the ACCESS community with sharing
data at NCI.

- Working Group Storage
- Sandbox
- Reference Datasets


## Working Group Storage

Each of the ACCESS Community working groups has a storage allocation to support
the group in their research efforts.
See this page for more information on [joining ACCESS working groups](https://www.access-nri.org.au/join-community-working-groups/).

Working group storage is ideal for data that is under active development, or only
needs to be shared within the working group.


## Sandbox

ACCESS-NRI maintains the ACCESS Data Sandbox on Gadi under the project `av17`.
The Sandbox supports datasets that may not be considered ready for publication or
are of value to be shared with the community.
Sandbox storage is ideal for stable data that needs to be shared amongst the community.


## Reference Datasets

ACCESS-NRI also supports a number of Reference datasets which are considered of
value to the community are intended for support broad access, use, and citation.
These datasets are more carefully curated, can be given DOIs, and can be exposed
to the public via NCI's THREDDS service.

## Comparison

|                 | Working Group           | Sandbox    | Reference Dataset |
| --------------: | :---------------------: | :--------: | :---------------: |
| *Timeframe*     | <12 months              | 1-2 years  | >2 years          |
| *Managed by*    | Working group and users | ACCESS-NRI | ACCESS-NRI & NCI  |
| *DOI*           | No                      | No         | Yes               |
| *Public Access* | No                      | No         | Yes               |
| *Sharing Scope* | Working group           | Gadi       | Global            |
