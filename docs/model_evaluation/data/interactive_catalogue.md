# What is ACCESS-NRI Interactive Data Catalog

The ACCESS-NRI Interactive Data Catalog is a web-based application that allows users to explore and discover climate data products available on the NCI Gadi supercomputer. It provides an intuitive interface for searching and filtering datasets based on various attributes such as variables, models, frequencies, and realms.

It also allows users to subset and query data in order to select the minimal subset of data files they wish to open on gadi, providing code snippets which allows a user to load the selected data within an ARE session using the ACCESS-NRI Intake Catalog.

It is not a separate catalog from the ACCESS-NRI Intake Catalog, but rather a complementary tool that provides a user-friendly way to interact with and share the same underlying data, without having to log into Gadi or write code in order to find data.
