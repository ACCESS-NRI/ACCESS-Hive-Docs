# ACCESS-NRI supported releases
Links included are release notes that are mostly posted on the [Hive Forum].

Information around release terminology and support can be found on [ACCESS-NRI Release Stages](about/releases).
Types are broad. notes. Other releases include training videos on youtube, visualisation and explainer videos.

- Model: Refers to climate model components and [configurations](about/releases/#fn:1).
- Tool: Refers to supporting tools which can be pre and post processing, evaluation and diagnostics.
- Data: Collections listed are curated collections which can include data required for model runs, observations for evaluation and some model outputs.
