# Dr Peter Dobrohotoff

![Dr Peter Dobrohotoff](../wp-content/uploads/2026/09/DSC_1916-BW-300x300.jpg){ .align-right }

**Research scientist**

Dr Peter Dobrohotoff has been working with the ACCESS model since joining CSIRO in 2012, first developing a high-resolution atmospheric model, then configuring, testing and tuning the coupled model for Phase 6 of the Coupled Model Intercomparison Project (CMIP6). Since then, he has been evaluating model projections, especially the drivers of projected changes in Australian rainfall. He has been the ACCESS data manager for the National Environmental Science Program (NESP) since 2022.

Peter completed his PhD in Astrophysics at the University of Sydney in 2013 with a theses entitled: “Towards a numerical radiative magnetohydrodynamic scheme for black hole accretion simulations”, which worked on a model to simulate relativistic flows around black holes.

At ACCESS-NRI, Peter works with the Data team to deliver ACCESS-ESM-1.6 experiments to the Phase 7 Fast Track of the Coupled Model Intercomparison Project (CMIP7) for the National Environmental Science Program (NESP). This involves post-processing raw ACCESS data into a standard format for publishing on the Earth System Grid Federation (ESGF), which is an international data infrastructure used to share the results of CMIP experiments. He particularly enjoys exploring the data, which he thiks is lots of fun, compared with radio astronomy, as the data reductions from raw telescope data were hard work. With ACCESS he feels there is huge amounts of really interesting data in an easily accessible standard format, which provides what seems like unlimited potential to explore the beautiful fluid dynamics and thermodynamics that the model simulates. The value of this work is to critically assess model performance and improve data quality.

Peter’s passions outside work are music, photography, tech, and all things physics.
