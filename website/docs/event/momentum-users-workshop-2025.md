# Momentum Users Workshop 2025

*June 9, 2025 - June 13, 2025*

**You can now register for the Momentum® User Workshop!**

Momentum is the next generation of the UK Met Office Unified Model. This includes the Momentum Atmosphere Model and the Momentum Partnership.

To register you will need to fill in the form: [Momentum User Workshop – Registration Form](https://aus01.safelinks.protection.outlook.com/?url=https%3A%2F%2Fforms.office.com%2FPages%2FResponsePage.aspx%3Fid%3DYYHxF9cgRkeH_VD-PjtmGenVwYe9WgZIn094FbTKHZ9UOElCRzFRWjBFOEhBSkNPMjA3S044VDk2Ri4u&data=05%7C02%7CNatalia.Bateman%40anu.edu.au%7C2460e83212464469941208dd9112053a%7Ce37d725cab5c46249ae5f0533e486437%7C0%7C0%7C638826228768074906%7CUnknown%7CTWFpbGZsb3d8eyJFbXB0eU1hcGkiOnRydWUsIlYiOiIwLjAuMDAwMCIsIlAiOiJXaW4zMiIsIkFOIjoiTWFpbCIsIldUIjoyfQ%3D%3D%7C0%7C%7C%7C&sdata=XXkbGEvLUoe8J2hhWQ7M0n%2BJKcMrpyZtA%2BxlLltsaQQ%3D&reserved=0)

If you would like to attend, please do register to the workshop even if you are working at the Met Office. This will allow us to better organise the workshop to know how many people will be attending.

As a note; you do not have to attend each session and you can indicate in the registration form which sessions you would like to attend.

Questions? Contact Marie Ozanne: [marie.ozanne@metoffice.gov.uk](mailto:marie.ozanne@metoffice.gov.uk)
