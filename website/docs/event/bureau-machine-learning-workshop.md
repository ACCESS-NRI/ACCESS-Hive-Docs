# Bureau Machine Learning Workshop

*August 17, 2026 - August 18, 2026*

The Bureau of Meteorology is holding a two-day **Bureau Machine Learning Workshop**, on 17–18 August.

This will be held as a pre-cursor to the **[ACCESS Community Workshop Connecting Machine Learning to Earth System Science](https://aus01.safelinks.protection.outlook.com/?url=https%3A%2F%2Fwww.access-nri.org.au%2Faccess-workshop-2026-connecting-machine-learning-to-earth-system-science%2F&data=05%7C02%7CNatalia.Bateman%40anu.edu.au%7C71c1af8e8afe40bde50908dee87c6496%7Ce37d725cab5c46249ae5f0533e486437%7C0%7C0%7C639203818161082846%7CUnknown%7CTWFpbGZsb3d8eyJFbXB0eU1hcGkiOnRydWUsIlYiOiIwLjAuMDAwMCIsIlAiOiJXaW4zMiIsIkFOIjoiTWFpbCIsIldUIjoyfQ%3D%3D%7C0%7C%7C%7C&sdata=xZGwYSpGGR8B%2FsHC8Jdwz5bjZfWWzByozrwx%2FCZp3io%3D&reserved=0)**, being held 19-21 August at the same venue, providing a valuable opportunity to connect Bureau priorities with the broader Australian research community.

The Bureau ML Workshop will bring together researchers and practitioners from across the weather, climate, ocean, water and hazards communities both in Australia and internationally to explore how physical, statistical, machine learning and hybrid approaches can work together to advance Australia’s future prediction capabilities.

Discussions will include the practical implications of adopting machine learning within public agencies, including evolving requirements for software systems, computing infrastructure, governance arrangements, and transparent, explainable approaches to verification and assessment.
