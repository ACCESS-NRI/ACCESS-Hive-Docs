# ACCESS data information session at AMOS 2026

*February 18, 2026*

## ACCESS climate model output data: Your roadmap to finding and working with the data

**7:30 am – 8:45 am; Hotel Grand Chancellor, Hobart; Free breakfast included!**

[Register here](https://forms.office.com/r/10P80JjEsQ){ .buttononblue }

*Curious about working with ACCESS climate model output?*

This informational session provides an overview of guidance and tools that together form a blueprint for working with ACCESS model output, helping researchers understand what’s available, how it’s organised, and how to get started with ACCESS model data on the National Computational Infrastructure (NCI). The focus is on building confidence with the ecosystem around the data, equipping participants with the knowledge and resources to use ACCESS model output in their own research workflows.

We’ll share tips and tools for effective ACCESS model data workflows on NCI, including how to search for and locate datasets, recommended Python environments, and suggested Python tools (like [Xarray](https://docs.xarray.dev/en/stable/)) to read and analyse the model output. We’ll also include a preview of some data discovery and processing tools currently being developed by ACCESS-NRI. Throughout, we’ll outline the data-related support ACCESS-NRI provides (such as storage space for your data) and point you to ongoing guidance, examples, and community resources to help you build and refine your own workflows. An optional hands-on activity at the end of the session will walk interested participants through using a prototype ACCESS-NRI data discovery tool to find and work with ACCESS model output data.

**Bonus:** As if talking about data isn’t exciting enough, breakfast is on us! (That’s right—enjoy a free breakfast while learning about ACCESS model output!)

**Please note:**

- *You must be registered for the AMOS Conference 2026 to attend this session.*
- *Time and location is subject to change as the AMOS program is finalised.*
- *This session is best suited for less experienced data users who already have—or are able to obtain—ongoing access to NCI compute resources after the workshop, so they can access and explore the data and apply the tools and tips introduced during the session in their own research.*

You may also like to consider ACCESS-NRI’s [ACCESS-rAM3: Hands-on regional modelling workshop](access-ram3-workshop-at-amos-2026.md) at the AMOS Conference 2026.

#### Learning objectives

1. Learn about the key tools and approaches for finding ACCESS model output on NCI
2. Become familiar with the tools and workflows used to access, explore, and analyse ACCESS model output
3. Understand the resources and support that ACCESS-NRI provides to help you work effectively with model output data
4. Engage with ACCESS-NRI data experts to ask questions and identify next steps for your own workflows

#### Prerequisites

Helpful but *not required*:

- Access—or the ability to obtain access—to NCI compute resources (recommended for participants who wish to explore datasets and apply the information from the session in their own workflows)
- Basic understanding of climate models
- Some familiarity with Python and Jupyter notebooks
