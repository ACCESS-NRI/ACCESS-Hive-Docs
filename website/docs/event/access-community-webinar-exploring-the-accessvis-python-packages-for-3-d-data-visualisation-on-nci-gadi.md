# Exploring the accessvis Python Packages for 3-D Data Visualisation on NCI Gadi

*December 6, 2024*

Following the insightful discussions at the ACCESS Community Workshop 2024, join the ACCESS Model Evaluation and Diagnostics team for an in-depth online session on Friday, 6th December, at 11 AM Canberra Time. This webinar will showcase the capabilities of the *accessvis* Python packages for Earth systems data visualisation, including examples optimised for GPU use on NCI Gadi.

**Details:**

- **Date:** Friday, 6th December
- **Time:** 11 am- 12 pm Canberra Time
- **Register:** [ACCESS Community Webinar Tickets, Fri, Dec 6, 2024 at 11:00 AM | Eventbrite](https://www.eventbrite.com/e/access-community-webinar-tickets-1100661140099)
- **Platform**: Zoom (link will be added here soon)

**Webinar Highlights:**

- Introduction to the *accessvis* Python packages.
- Step-by-step examples for visualising 2-D and 3-D data.
- Live demonstration on using GPU resources to enhance visualisation performance.

More information and to ask questions in the ACCESS-Hive Forum: <https://forum.access-hive.org.au/t/access-community-webinar-exploring-the-accessvis-python-packages-for-3-d-data-visualisation-on-nci-gadi/3883>

**This is a valuable opportunity for the community to gain hands-on insights into using Gadi’s GPU resources for advanced data visualisation. Don’t miss it!**
