# Join the ACCESS Community

If you are a model developer or an user of the ACCESS models, outputs or tools, or if you are simply interested on using them for you research, you are part of the ACCESS Community! There are several ways to join the ACCESS Community:

![](wp-content/uploads/2025/09/Join-the-Community-570x320.png)

## This is a forum for the ACCESS community

Join the conversation!

[Visit the ACCESS-Hive Forum](https://forum.access-hive.org.au/){ .buttononblue }

![](wp-content/uploads/2025/09/Join-the-Community1-570x320.png)

## These six Groups are open to everyone

Attend meetings, collaborate and ask questions

[Join a Community Working Group](working-groups/index.md){ .buttononblue }

![](wp-content/uploads/2025/09/Join-the-Community2-570x320.png)

## Receive updates directly to your inbox!

Subscribe to receive news and updates from ACCESS-NRI and the ACCESS Community

[Subscribe](https://access-nri.us14.list-manage.com/subscribe?u=2e82a242a5023d286ad0d4555&id=aed3bbbb13){ .buttononblue }
