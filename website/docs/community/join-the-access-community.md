# Join the ACCESS community

The ACCESS Models are used by a diverse community of Australian and international researchers, working in many areas of science.If you currently use the ACCESS models or are interested on using them for you research, we would love to hear from you!

Join the community by registering to our two main channels of communication with the ACCESS community:

![](../wp-content/uploads/2022/11/ACCESS-icon-HIVE-Title-300x300.png){ .align-left }

The [ACCESS-Hive](https://access-hive.org.au/) User Portal

![](../wp-content/uploads/2023/08/ACCESS-icon-FORUM-Title1-300x300.png){ .align-left }

The [ACCESS Hive Forum](https://forum.access-hive.org.au/)

Or use [this form](https://us14.list-manage.com/survey?u=2e82a242a5023d286ad0d4555&id=4fb77b4e37&attribution=false) to let us know how you have been using ACCESS.
