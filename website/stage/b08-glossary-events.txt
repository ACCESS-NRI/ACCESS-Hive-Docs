Here you can find a compilation of common terms and acronyms used by the ACCESS community:

| Name | Description |
| --- | --- |
| ACCESS | Australian Community Climate and Earth System Simulator |
| ACCESS-AM2 | ACCESS Atmospheric Model 2 is the ACCESS-CM2 Model Configuration without the ocean component (ACCESS-OM2) |
| ACCESS-CM2 | ACCESS Coupled Model version 2 |
| ACCESS-CM2-Chem | ACCESS-CM2 extended configuration that simulates atmospheric chemistry from the surface to the stratosphere. |
| ACCESS-ESM1.5 | ACCESS Earth System Model Version 1.5 |
| ACCESS-MOM | ACCESS-MOM5 is a numerical ocean model |
| ACCESS-OM2 | ACCESS Ocean Model Version 2 |
| ACCESS-S | ACCESS-Seasonal Prediction System |
| AM | Atmospheric Modelling |
| AMOS | The Australian Meteorological and Oceanographic Society |
| BARRA | Bureau of Meteorology Atmospheric high-resolution Regional Reanalysis for Australia |
| BGC | Biogeochemistry |
| BRAN | BlueLink Reanalysis |
| CABLE | Community Atmosphere-Biosphere Land Exchange model |
| CASA-CNP | Carnegie Ames Stanford Approach-Carbon Nitrogen Phosphorus |
| CERFACS | Centre Européen de Recherche et de Formation Avancée en Calcul Scientifique |
| CICE | ACCESS Sea-Ice Model |
| CM | Coupled Model |
| CMIP | Coupled Model Intercomparison Project |
| COSIMA | Consortium for Ocean-Sea Ice Modelling in Australia |
| ECS | Equilibrium Climate Sensitivity |
| ENSO | El Niño–Southern Oscillation |
| ESMValTool | Earth System Model Evaluation Tool |
| GFDL | Geophysical Fluid Dynamics Laboratory, US National Oceanic and Atmospheric Administration |
| GLOMAP | Global Model of Aerosol Processes |
| Gadi | Gadi (pronunced ‘Gar-dee’ is an Indigenous word meaning Knowledge) is NCI's high performance computer where the ACCESS models are located. |
| HPC | High Performance Computing |
| IOD | Indian Ocean Dipole |
| JULES | Join UK Land Exchange Simulator (UK land model) |
| LANL | Los Alamos National Laboratory |
| MED | Model Evaluation and Diagnostics |
| MOM | Modular Ocean Model |
| NCRIS | National Collaborative Research Infrastructure Strategy |
| NEMO | Nucleus for European Modelling of the Ocean |
| NGMS | Next Generation Modelling System |
| NUOPC | National Unified Operation Prediction Capability |
| NWP | Numerical Weather Prediction |
| OASIS | Originally "Ocean Atmosphere Sea Ice Soil", but now represents a project to develop general coupling software |
| SAC | Scientific Advisory Committee |
| SSP | Shared Socioeconomic Pathways |
| UKMO | United Kingdom Meteorological Office (also referred to as the Met Office) |
| UM | Unified Model (Atmosphere) |
| WCRP | World Climate Research Program |
| WOMBAT | Whole Ocean Model of Biogeochemistry And Trophic-Dynamics |
| YATM | Yet another data-driven atmosphere model |
